# Small Space Planner

English-language content and planning-tool site focused on studio apartment layouts, compact-home storage and furniture placement.

## Stack
- Next.js
- TypeScript
- Vercel

## Launch controls
The Vercel preview is intentionally blocked from indexing until the permanent domain is ready.

Environment variables:
- `NEXT_PUBLIC_SITE_URL`
- `NEXT_PUBLIC_ALLOW_INDEXING=true` only when the permanent domain is ready for Google
- `NEXT_PUBLIC_ADSENSE_CLIENT` after AdSense approval

AdSense remains dormant until the permanent domain, consent setup and publisher account are ready.


## Launch checklist

Current preview: https://small-space-lab.vercel.app

The site intentionally remains blocked from indexing during pre-launch.

Before public indexing:
1. Connect the permanent domain and set `NEXT_PUBLIC_SITE_URL`.
2. Add a real contact channel for the permanent domain.
3. Configure Search Console and analytics.
4. Confirm privacy/cookie wording against the services actually enabled.
5. Set `NEXT_PUBLIC_ALLOW_INDEXING=true`.
6. Submit the production sitemap.
7. Add AdSense/consent configuration only after publisher approval.

Do not enable advertising on the preview URL.
